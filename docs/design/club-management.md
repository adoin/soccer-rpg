# 俱乐部经营

业余联赛这一档要能当一整个赛季来管，不是只排一场比赛。数据放在生涯存档里，规则做成内置 mod `club`，别的联赛可以换数字、换窗口，不必改比赛引擎。

存档正文从 schema 1 升到 2。旧档读进来只补缺的字段，阵容、积分和预算不动。

## 谁拥有什么

一家俱乐部（玩家的 `save.club`，对手队用各自 `team` 上的精简字段）：

| 字段 | 含义 |
|---|---|
| cash | 和 `save.budget` 是同一笔钱 |
| wageBudget | 周薪上限，超了财务页会标红 |
| history | 流水：工资、门票、奖金、赞助、转会、租借 |
| board | 本赛季名次期望和一句话 |
| tactics | 阵型、压迫、防线、传球、节奏、宽度、队长、定位球主罚 |
| training | 全队侧重，以及每人的个人侧重 |
| academy | 青训教练档次和青训名单（不占一线 22 人） |
| inbox | 消息 |
| loans | 租出 / 租入记录 |

球员在原有年龄、能力、周薪之外：

| 字段 | 含义 |
|---|---|
| contractEnd | 合同打到哪个赛季结束（含该赛季） |
| clause | 解约金，可以没有 |
| morale | 0–100，影响表现和续约 |
| condition | 0–100，跨比赛的疲劳。100 是满状态 |
| potential | 隐藏潜力。界面给估计星 |
| growth | 最近一次训练的升降，用来画箭头 |
| minutes | 本季出场（首发记 90，替补记 25） |
| injury | `{ matches, label }` 或空 |
| ban | 还要停赛几场 |
| yellows | 累计黄牌，满 4 张停一场并清零 |
| loan | 租借：方向、俱乐部、剩余场次、工资分担、能否召回 |

比赛里的 `stamina` 仍是这一场的体力，打完折算进 `condition`。

## 十二块怎么转

1. **财务。** 每个比赛日扣全队周薪。主场有门票，赢球有奖金，每四周一笔赞助。数字跟联赛条目上的 `gate` / `prize` / `sponsor` 走，业余联赛就是小钱。流水留在财务页。董事会按名次期望说话，赛季末达标给一笔奖金，垫底扣一点预算。
2. **合同。** 续约看能力、年龄和士气开价。出价够就签，差一点还价，差得多拒绝。到期的人在新赛季开始时自由离队。市场上的自由球员可以直接签，只谈工资。
3. **转会。** 对手会出价买你的人（接受 / 拒绝 / 还价）。你也可以向别的队出价。成不成就看报价和球员愿不愿意（士气、出场、年龄）。窗口写在赛事上：业余联赛 `window: 'always'`，整季都能交易。别的赛事可以把窗口收成夏窗。
4. **租借。** 租出或租入，写明场次、工资谁出、能不能中途召回。租出去的人不能进自己的首发，算在对方名单里，比赛日照常成长一点。到期或召回就回来。
5. **青训。** 青训营单独成队。每个新赛季进 3 个 16 岁少年，潜力藏着，界面给估计星。教练档次影响他们长得多快。可以提拔上一线（一线没满的时候）或放走。
6. **训练。** 每周一次全队侧重：身体、技术、战术、休息。还可以给个人再指定一项。年轻、潜力高、有出场的人长得快；30 岁以后开始掉。休息少掉状态、少受伤。变化记在箭头上。
7. **战术。** 阵型（4-2-3-1、4-4-2、4-3-3、3-5-2）、压迫、防线高低、传球长短、节奏、宽度、队长和定位球。这些会写进比赛：阵型槽、上抢人数、防线位置、传球偏好、带球速度。暂停菜单里可以换阵型、改压迫，以及换人（一场最多 3 个）。
8. **体力。** 冲刺、跑动、对抗、上抢都掉体力，停球和中场休息回一点。体力低的时候速度、加速、传射、抢断、对抗一起打折。阵容条和球员卡上有体力条，低了变红。对手体力太差会在中场换人。状态百分比写在阵容和首发上，状态差会提示。
9. **伤病和停赛。** 体力见底或状态很差有机会受伤，伤好几场。黄牌累到 4 张，或直红，停一场。受伤和停赛的人排不进首发。
10. **士气。** 赢球、出场、续约顺利会涨；输球、该上不上、谈崩了会掉。士气轻轻影响场上能力和续约意愿。
11. **赛季。** 赛程的每一轮就是一个比赛周：可以自己踢，也可以模拟。消息页收出价、合同、伤病、青训和董事会的话。赛季结束给出队内奖项。名次钩子留给升级降级，业余这一档只发奖金和警告。新赛季年龄加一，36 岁退役，合同到期离队，青训再进一批人。
12. **对手。** 别的队也会按状态轮换，隔几轮做一笔简单转会。没有你参加的比赛用同一套能力和状态去算比分。

## 钩子

`club` 走现有的 `onSeasonStart`、`onMatchPlayed`、`growPlayers`、`youthIntake`、`onLoad`。赛事数据（窗口、门票、奖金、赞助、名次期望）放在 `competitions` 的条目上，不写死在俱乐部逻辑里。
