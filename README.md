# 热血足球 RPG · Demo

致敬早期游戏机《天使之翼》（Captain Tsubasa / Tecmo Cup）的**回合指令制足球 RPG** 网页 demo。

你执教 **青鹰高校**（蓝色），在持球球员遭遇防守的「决策点」从 6 种指令中做选择；
对手 **烈风学院**（红色）由服务器 AI 执教。所有判定都在服务器完成，可放心演示。

## 快速运行

```bash
npm install
npm start
```

浏览器打开 **http://localhost:3000** 即可开始比赛。

- 半场时长可在标题画面选择（1 / 3 / 5 分钟，默认 3 分钟）
- 操作方式：当持球球员接近防守球员时，比赛暂停并弹出指令菜单，
  用鼠标点击指令即可；`Esc` 或右上角按钮可暂停 / 打开暂停菜单

## 玩法

6 种指令（括号内为精神消耗，成功率由服务器按双方数值实时计算并显示）：

| 指令 | 消耗精神 | 说明 |
|---|---|---|
| 突破 | 20 | 带球过掉最近的防守球员 |
| 传球 | 15 | 传给位置最好的队友 |
| 射门 | 30 | 起脚射门，离门越近成功率越高 |
| 必杀技 | 60 | 球员专属必杀射门（如「疾风射门」），仅前锋/中场可用 |
| 假动作 | 20 | 晃开防守球员并使其短暂僵直 |
| 回撤 | 0 | 安全带球回撤，不耗精神 |

暂停菜单：继续比赛 / 战术指令（均衡·进攻·防守）/ 球员状态 /
比赛设定 / 回放（占位）/ 退出比赛。

## 架构（服务器权威 · 防作弊）

```
client/  原生 HTML5 Canvas + JS，只负责渲染与采集输入
         像素风角色全部由代码逐像素绘制（js/sprites.js），无外部素材
server/  Node.js + Express
  game/engine.js   比赛引擎：位置模拟、AI、无球跑位、指令结算（唯一真相源）
  rng.js           服务器端 RNG（mulberry32，每场比赛独立种子，不暴露给客户端）
shared/  前后端共用的常量与阵容数值（UMD 模块）
```

**防作弊设计：**

1. 全部关键数据（球员位置、体力/精神、比分、时钟）只存在服务器内存，
   客户端只能轮询读取快照，不能写入。
2. 客户端唯一能发送的是 `{ matchId, commandId }`。服务器逐项校验：
   是否正处于「等待该用户决策」阶段、球员身份是否匹配、指令是否合法、
   精神是否足够——非法请求直接拒绝。
3. 成功率计算与掷骰全部使用服务器端 RNG，客户端无法预测或篡改结果；
   对手 AI 与无球跑位同样在服务器运行。

通信方式：REST 轮询（`GET /api/match/:id/state` 每 300ms），简单可靠；
决策与结算是同步请求，事件序列随状态快照下发、由客户端播放动画。

## 体能设计（区别于《天使之翼》）

- **技能只消耗「精神」，不消耗体能**——这是本作与《天使之翼》最大的不同，
  鼓励玩家积极使用技能。
- **体能**只因跑动缓慢下降（持球跑动稍快）、随时间缓慢恢复；
  体能过低会轻微降低实际能力（速度与对抗系数 0.9~1.1）。
- **精神**随时间缓慢恢复，中场休息时体能/精神部分回复。

相关实现：`server/game/engine.js` 的 `updateEnergy()` 与各指令的 `cost` 扣除；
指令消耗定义在 `shared/constants.js`。

```

├── server/

│   ├── index.html
│   ├── css/style.css
│   └── js/
│       ├── sprites.js    程序化像素精灵

└── README.md
```

## 后续可扩展（当前为占位或简化）

- 回放功能：暂停菜单中的「回放」目前仅提示，事件序列已由服务器下发，
  接入时间轴回放即可实现。
- 比赛事件：当前无角球/任意球/犯规/换人，射门被扑或偏出后球权直接给对方门将。
- 上下半场未交换场地；越位规则未实现。
- `matchId` 目前为随机串，建议上线前绑定用户会话，防止他人冒用 id 操作比赛。
- 客户端渲染位置为插值平滑，弱网下会有轻微延迟感；可升级为 WebSocket 推送。
- 数值平衡、更多必杀技演出、球员成长/养成系统均为预留扩展点。
